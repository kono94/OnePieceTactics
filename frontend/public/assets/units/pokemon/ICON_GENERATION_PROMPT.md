# Pokemon Icon Batch Prompt Example

Use this prompt format with the approved style reference image attached in the
image-generation chat. The reference controls the pixel-art style; the prompt
controls the four Pokemon, deterministic type background colors, and no-divider
2x2 layout.

```text
Create a single 1024x1024 image split into four equal quadrants for auto-battler unit icons. I will provide a reference image of the style that should be used but the Pokemon should be a tiny little bit more visible, not just the face and shoulders.
Top-left: Mr. Mime on a flat soft pastel Psychic-type background #F6C7E6 with subtle psychic aura pixel accents.
Top-right: Pinsir on a flat soft pastel Bug-type background #D8F5A6 with subtle pollen pixel accents.
Bottom-left: Lapras on a flat soft pastel Water-type background #BFEFFF with subtle bubble and ice-mist pixel accents.
Bottom-right: Tauros on a flat soft pastel Normal-type background #E9E6DE with subtle dust pixel accents.
Style: close-cropped Pokemon portrait with head and upper body visible, modern high-quality pixel art, thick dark navy/black pixel outline, chunky pixel grid, saturated cel-shaded colors, crisp edges, centered and filling most of each quadrant. No text, no watermark, no UI frame, no decorative border, no black grid lines, no visible divider lines between quadrants.
```
